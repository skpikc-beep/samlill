# تطوير الشعار — باب الهروب (Escape Door)

نسخة مطوّرة من شعار الشريط السداسي `S`، تُضيف **باب هروب واقعياً** بروح هندسية نظيفة،
من دون أي عنصر بشري: إطار معماري ولوحٌ بمفصّلات ظاهرة وذراع دفع أفقي، مفتوح جزئياً ليخرج
منه الضوء، وتحيط بالشكل خطوط إنشائية رقيقة تعطيه دقّة المخططات الهندسية

## المفهوم

| العنصر | الدلالة |
| --- | --- |
| الشريط السداسي `S` | قوة، حماية، واستمرار الحركة (المسار يدور ولا ينتهي) |
| فتحتا الشكل من الجانبين | لا حصار — الفراغ السالب يوحي بالانفتاح |
| إطار الباب ولوحه | باب هروب حقيقي (Emergency Exit) بأبعاد معمارية واضحة |
| المفصّلات وذراع الدفع | تفاصيل وظيفية تُقرأ فوراً كباب طوارئ، وبلا أي شخص يعبره |
| الخطوط الهندسية الرقيقة | دقّة إنشائية (Construction lines) تُثبّت الشكل وتُبرز المحاور |
| هالة الضوء الدافئة | الأمل/المخرج، وتعمل كتوقيع لوني مميّز للعلامة |
