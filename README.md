# تطوير الشعار — باب الهروب (Escape Door)

نسخة مطوّرة من شعار الشريط السداسي `S`، تُضيف مفهوم **باب الهروب** بشكل تجريدي كامل،
من دون أي عنصر بشري: لوح باب يدور على محوره داخل مركز الشكل، وفتحة شقّ يخرج منها الضوء
إلى الفراغ السالب.

## المفهوم

| العنصر | الدلالة |
| --- | --- |
| الشريط السداسي `S` | قوة، حماية، واستمرار الحركة (المسار يدور ولا ينتهي) |
| فتحتا الشكل من الجانبين | لا حصار — الفراغ السالب يوحي بالانفتاح |
| لوح الباب المائل | الخروج متاح دائماً، بلا مفصل ظاهر ولا شخص يعبره |
| هالة الضوء الدافئة | الأمل/المخرج، وتعمل كتوقيع لوني مميّز للعلامة |
